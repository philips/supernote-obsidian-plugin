<supernote-atelier-viewer> demo

Standalone build of the <supernote-atelier-viewer> custom element from the supernote-obsidian-plugin project - runs entirely in this page, with no Obsidian involved. Pick a .spd file (a Supernote Atelier document) from your device to view it, toggle its layers, and zoom in.

Build the bundle first: this page loads ../dist/supernote-atelier-viewer.js, which isn't checked into the repo - run npm run build:atelier-webcomponent from the project root, then serve this directory over http(s) (module scripts can't load from a file:// URL) - e.g. npx serve . from the project root, then open /demo/atelier.html.
